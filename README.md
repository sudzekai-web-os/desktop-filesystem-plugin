# Файловая система для LinCtrl Desktop

Скопируйте содержимое каталога `plugin` в папку `filesystem.linctrl` внутри `plugins` рядом с LinCtrl Desktop. Включите плагин в разделе «Плагины» и войдите на сервер с соответствующим серверным плагином.

Папки и файлы текущего каталога показаны в одном списке. Адресная строка начинается с `root:\` и показывает путь внутри единственного каталога, заданного на сервере через `Filesystem:Root`. Двойной щелчок открывает папку или содержимое файла. Правый щелчок по объекту показывает доступные действия. Правый щелчок по пустой области открывает меню создания. Для создания в текущей папке укажите только название. Права доступа отображаются в свойствах файла и папки. Администратор может создавать, копировать, перемещать и удалять объекты, редактировать текст. Редактор автоматически отправляет небольшой набор замен по номерам строк. При вставке, удалении или большом числе изменений он отправляет полный текст.

Запросы выполняет `PluginRequest` из модуля `linctrl`. Он использует JWT текущей сессии и разбирает JSON-обёртку серверного ответа.

Иконки навигации, папок и файлов взяты из Bootstrap Icons (лицензия MIT находится в каталоге icons).

Импорт локального файла доступен в меню пустой области, экспорт — в меню выбранного файла. Действия работают с бинарными и текстовыми файлами до 8 МиБ.
